# Better Special Weapons / 更好的特种武器

《隔离区》（ZED ZONE）特种武器底层修复与体验重做模组（BepInEx 6 IL2CPP，MIT 开源），针对原版 4 把特殊机理武器——**特斯拉枪（467）**、**采矿激光器（466）**、**M2 火焰喷射器（468）**与**高压喷水枪（469）**——彻底解决帧率依赖、耗电/耗液公式错误、假面板数值与喷射沿途无伤害等问题。

- **前置依赖**：ZED ZONE Code Mod Loader（Steam Workshop ID: `3834614258`）
- **多人联机说明**：本模组调整武器属性与伤害计算，**多人联机需房主与所有客户端一致安装**（敌方喷火丧尸与机甲武器完全不受影响）。

---

## 核心改动

1. **特斯拉枪（467）**
   - **高频脉冲 + 通用面板同步**：默认改为 **`60` 单次伤害 × `30` 次/秒**（总基础单体 DPS `1,800`，3 链导电最高约 `4,220` DPS），主光束与连锁电弧同频触发，面板直接同步显示真实伤害与射速（面板攻速 `1,800` 对应每分钟脉冲数），完全脱离渲染帧率影响；每一跳均稳定越过原版受击硬直门槛（`10`）。
   - **大范围自动锁敌与躯干视觉锁定**：单目标连锁锁定模式，沿“枪口 → 鼠标”方向提供宽范围电弧自动索敌（默认 `1.8m`，可在 `0 ~ 4.5m` 间调节或设为 `0` 关闭）：优先锁定准星附近无墙遮挡的敌人，其次沿射击走廊自动捕捉前方目标，同时将视觉电弧端点直接锁定在被命中敌人的躯干中心，避免指向敌方脚底或穿模击打地面。
   - **耗电与环境破坏**：按真实流逝时间严格执行标称 `50/s` 耗电；对树木/石头等环境物体破坏默认保持 `1.0×` 原版基准，支持在配置中按需调低。
2. **采矿激光器（466）**
   - **高频脉冲 + 穿甲修复**：默认改为 **`80` 单次伤害 × `30` 次/秒**（纯单体高伤定位，基础单体 DPS `2,400`，对单高于特斯拉枪），同步面板显示，修复原版命中角色误传 `deathMultiplier = 1` 的问题，同时完整保留原版挖矿与拆墙效率。
3. **M2 火焰喷射器（468）与高压喷水枪（469）**
   - **全路径穿透与贴脸盲区修复**：解决原版复用抛射爆炸组件导致“火舌/水柱穿过近处或完全贴脸丧尸却只有鼠标落点才起效”的问题。在枪口近身盲区及沿途走廊同步判定命中：喷火器火舌从贴脸到射程沿途穿透灼烧并点燃目标，自动排除落点爆炸圆内目标以避免双倍叠伤，遇到实心墙体自动截断。
   - **高压喷水枪击退与全场景灭火**：新增按目标质量自适应的速度击退（普通丧尸击退明显，重型 Boss 抗击退更强）与 4 层灭火机制——自动扑灭沿途与落点半径（默认 `2.2m`）内的地面火焰、燃烧物体、燃烧尸体、体素火以及角色燃烧状态（含友军与自身），并附带灭火音效与水渍抑制复燃。
   - **真实时间耗液与诚实面板**：修复按固定 60 帧扣液 Bug，改为严格按真实时间消耗；直伤 DPS 稳定可配（喷火器默认 `1,400` + 原版燃烧 DoT，水枪默认 `120`；面板攻速显示 `3,000` 即 `60 / 0.02s = 3,000 RPM` 连续喷射频率）。

---

## 配置文件

首次启动游戏后自动生成：`BepInEx/config/zedzone.betterspecialweapons.cfg`，所有伤害、攻速、磁吸半径、穿透开关与消耗倍率均可自由调整。

## 源码构建

```powershell
pwsh -NoProfile -File .\build.ps1
pwsh -NoProfile -File .\build.ps1 -Install
```
