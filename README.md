# Better Special Weapons / 更好的特种武器

《隔离区》（ZED ZONE）特种武器底层修复与体验重做模组（BepInEx 6 IL2CPP，MIT 开源），针对原版 4 把特殊机理武器——**特斯拉枪（467）**、**采矿激光器（466）**、**M2 火焰喷射器（468）**与**高压喷水枪（469）**——优先修复假面板数值、帧率依赖耗电耗液、长体型 Boss 零伤与喷射盲区等底层缺陷，并完成手感和功能平衡重构。

- **前置依赖**：ZED ZONE Code Mod Loader（Steam Workshop ID: `3834614258`）
- **多人联机说明**：本模组调整武器属性与伤害计算，**多人联机需房主与所有客户端一致安装**（敌方喷火丧尸与机甲武器完全不受影响）。

---

## 核心底层修复

1. **真实面板同步（所见即所得）**：原版光束与液体武器面板显示的单发伤害与实际每帧 DPS 严重脱节。本模组按真实高频射速换算并同步 `damage` 与 `fireInterval`（例如 `3,000 RPM` 即 `60 / 0.02s` = 每秒 50 次连续判定）。
2. **帧率无关伤害与耗电/耗液修复**：修复原版光束随渲染帧乱跳伤害、电量公式漏扣、以及喷火器/水枪按固定 60 帧扣液的 Bug，严格按真实流逝时间消耗能源/燃料/水量并恒定输出。
3. **喷射盲区与多部位 Boss 零伤修复**：原版爆炸圆仅按目标根节点距离判定且撞前排即截断，导致变异巨蜥等长体型 Boss 命中头尾不掉血、贴脸僵尸吃不到伤害。

---

## 各武器具体改动

1. **特斯拉枪（467）**
   - **高频同频脉冲**：改为 **`36` 单次伤害 × `50` 次/秒**（面板显示 `3,000` 攻速，基础单体 DPS `1,800`，3 链导电最高约 `4,220` DPS），主光束与连锁电弧同频触发并同步至面板，每一跳稳定越过受击硬直门槛（`10`）。
   - **走廊优先索敌 + 躯干视觉锁定**：单目标连锁锁定模式，沿“枪口 → 鼠标”方向提供大范围自动索敌（默认 `1.8m`，可在 `0 ~ 4.5m` 调节或设为 `0` 关闭）：优先锁定射击走廊前方最近且无墙遮挡的敌人，其次抓取准星周围目标；视觉电弧末端直接锁定敌方躯干中心，避免跨怪指向地板造成穿模错觉。
   - **耗电与环境破坏**：按真实时间严格执行标称 `50/s` 耗电；树木/岩石等环境破坏默认保持 `1.0×` 原版基准，支持配置调低。
2. **采矿激光器（466）**
   - **纯单体高伤脉冲**：改为 **`48` 单次伤害 × `50` 次/秒**（面板显示 `3,000` 攻速，基础单体 DPS `2,400`，对单定位高于特斯拉枪），并优化击杀时的物理击飞力度（原版受 `bulletNumber=1` 影响几乎无击飞，可配，默认 `25`），同时完整保留原版挖矿与拆墙效率。
3. **M2 火焰喷射器（468）**
   - **全路径穿透与贴脸盲区修复**：补齐枪口近身环形检测与枪口到落点前的火舌穿透灼烧并点燃目标，贴脸及中段丧尸都能吃满伤害；自动排除落点爆炸圆内目标避免双倍叠伤，遇到实心墙体自动截断。
   - **诚实面板与真实油耗**：直伤 DPS 默认 `1,400`（对应 `3,000 RPM` 下单团 `28` 直伤 + 原版燃烧 DoT），可在配置中自由调整，按真实时间扣燃料。
4. **高压喷水枪（469）**
   - **真实耗水与诚实面板**：修正按帧乱扣水量的 Bug，默认 `120` 直伤 DPS（定位功能型辅助武器）。
   - **质量自适应击退 + 全场景 4 层灭火**：新增按目标刚体质量自适应的速度击退（普通丧尸击退明显，重型 Boss 抗击退更强）与 4 层灭火机制——自动扑灭沿途与落点半径（默认 `2.2m`）内的角色燃烧状态（含友军与自身）、地面火焰并铺设水渍抑制复燃、燃烧物体与尸体、体素屋顶/墙体火焰，并附带原版灭火音效。

## 配置文件与建议

首次启动游戏后自动生成：`BepInEx/config/zedzone.betterspecialweapons.cfg`，所有伤害、攻速（`10 ~ 100 Hz`）、索敌半径、穿透开关、击退与灭火半径、耗电/耗液倍率均可按需调整。欢迎在 Steam 创意工坊或 GitHub Issues 提出手感建议与反馈！

## 源码构建

```powershell
pwsh -NoProfile -File .\build.ps1
pwsh -NoProfile -File .\build.ps1 -Install
```
